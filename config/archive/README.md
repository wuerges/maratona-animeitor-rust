# Archived contest configurations

This directory contains historical contest configurations that are no longer
active. They remain in the repository for reference and migration work, but
new contests should use a manifest under `config/` and the root Makefile.

Archived directories:

- `fase-zero-2025`
- `latam_2024_2025`
- `latam_2025_2026`
- `nacional_2024`
- `nacional_2025`
- `regional_2024`
- `regional_2025`

The `legacy/` subdirectory contains the pre-manifest TOML files used by the
older server and Docker workflows.
